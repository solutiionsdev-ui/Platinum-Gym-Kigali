# Gym System

Demo gym system by solutiions.dev: public website, CRM for the owner and staff, WhatsApp assistant for the owner and WhatsApp automations for members.

## What's in this folder
- `BRIEF.md`: the full project: scope, design, rules, data, build steps
- `CLAUDE.md`: rules Claude Code follows in every session
- `KICKOFF.md`: the prompts to paste, step by step
- `PROGRESS.md`: what's done and what's next

## Branches
- `main`: approved, stable version
- `mario-branch`: Mario's work
- `michel-branch`: Michel's work

## How to start (Mario)
1. Open the **Claude** desktop app → **Code**.
2. Choose this folder: `SOLUTIIONS WEBSITE /GYM-CRM-WEBSITE`.
3. Open `KICKOFF.md`, copy the next step's prompt and paste it.
4. When a step is done you get a link like `http://localhost:3000`. Open it in Chrome and test it, then move to the next step.
